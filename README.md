## 製品概要

### 背景(製品開発のきっかけ、課題等）
暗い夜道を一人で歩くのは怖いものです。JPHACKS 2022 で審査委員特別賞を受賞した[「安心夜道」](https://github.com/jphacks/B_2220)でもテーマになっているように、多くの人が同じ不安を抱えています。
背後に人の気配を感じて、何度も振り返ってしまった経験は誰にでもあるはずです。しかし背後は死角なので、すぐ後ろまで迫られてから気づいたのでは、逃げる時間がありません。

この不安は、歩いている本人だけのものではありません。友人や家族の帰りが遅いとき、待っている側も「無事に帰れるかな」と心配になります。

何かが起きたあとの安心は、「安心夜道」のような既存のアプリやサービスがすでに支えています。一方で、**何かが起きる前に気づいて備える**ことは、既存のサービスではできていません。私たちはそこに着目しました。

「何かが起きても大丈夫」から、「何かをそもそも起こさせない」へ。
USHIROMI は、夜道を歩く本人と、帰りを待つ人の両方の「安心・安全」を守ります。

### 製品説明（具体的な製品の説明）
<p align="center">
  <img src="assets/hardware/device.jpg" alt="リュックの上に固定した USHIROMI の試作機：背後向きの ToF センサーと Raspberry Pi 4" width="420">
</p>

リュックの上に、ToF センサー（Arducam ToF B0410）を背後に向けて、処理をする Raspberry Pi 4 と一緒に固定して使います（試作では布テープで固定）。センサーと Pi のケーブルは短い（15cm）ので、Pi はセンサーのすぐ近くに置きます。モバイルバッテリーはリュックの中に入れます。

1. センサーが背後の距離（深度）と振幅（反射の強さ）を 30fps で取得する
2. 振幅画像から YOLOX-Nano で人を検出し、深度から人までの距離を求める
3. 人を追跡して、接近速度と衝突までの時間（TTC）を計算する
4. 近づいてくる人がいると、2〜3m 手前でブラウザの画面が赤くなり、警告音が鳴る（ゆっくり近づく人も、速く迫る人も知らせる）

画面は 3D 表示で、自分を中心にした背後の点群に、人を囲む円柱が出ます（2D の深度表示にも切り替えられます）。
Pi が Web サーバーを兼ねるので、PC やスマホはブラウザで開くだけです。何もインストールしません。

**スマホでも使えます。** 歩きながら手元のスマホで背後の様子を確かめられ、警告音もスマホから鳴ります。画面はスマホの縦長の画面にも合わせて表示します。Pi とスマホは同じ Wi-Fi（スマホのテザリングでもよい）につなぎます。

### 特長
#### 1. カメラ映像を使わない
明るい道ならカメラ映像でも人を見つけられますが、暗い夜道ではカメラにはほとんど何も映りません。
そこで、自分で光を出して距離を測る ToF センサーの距離画像で人を検出します。暗闇でも動き、通行人の顔も映らないので、プライバシーにも配慮できます。

#### 2. 距離画像での検出と追跡
Raspberry Pi で動く軽量なモデル（YOLOX-Nano）で人を検出し、追跡します。
検出には既存の学習済みモデルを使い、センサーの画像（4:3）に合わせて入力を 256×192 に書き出し直すことで、精度はそのままに約 3 倍速くしました。
重視したのは「自分に近づいてくる人」を確実にとらえることです。近づく速さと TTC から、ゆっくり近づく人も、遠くから走ってくる人も知らせます。

#### 3. 背後を 3D で見られる
背後の様子を、自分を中心にした 3D の点群で表示します。人は円柱で囲むので、何 m 後ろに誰がいるかがひと目で分かります。
暗い所で見る画面なので、背景は暗いまま、文字や点ははっきり見えるようにしています。

#### 4. 歩く本人だけでなく、帰りを待つ家族や友人も安心できる
夜道を歩く本人だけでなく、帰りを待つ家族や友人の不安を取り除くことも目指しています。
リンクを共有すると、家族や友人が自分のスマホから背後の様子をリアルタイムで見られます（今は同じ Wi-Fi の中だけ）。
背後の様子から無事に歩いているかが分かるので、待っている家族や友人も安心できます。

### 解決出来ること
- 死角になる背後から、気づかないうちに人が迫ることを防ぐ
- 画面を見続けなくても、接近を音と色で知る（近いほど音が強くなる）
- 共有リンクから、家族や友人がスマホで同じ画面を見て見守れる

### 今後の展望
- **ネット越しの見守り**：今は同じ Wi-Fi の中だけで見られます。離れた家族や友人がスマホから見られるようにします
- **画面を見なくても気づける**：イヤホンからの音や、左右の音で方向を知らせます
- **ついてくる人に気づく**：同じ距離でずっとついてくる人を見つけて知らせます
- **小さく、身につけやすく**：Pi とセンサーを小さなケースにまとめ、バッテリーで長く動くようにします
- **遠くの人も早く見つける**：今は 2〜3m 手前で知らせています。集めた ToF の画像で検出を学習し直し、遠く（3〜4m）の人や横向きの人も見つけて、もっと早く知らせます

### 注力したこと（こだわり等）
* 検出（YOLOX、約 5fps）と、距離・追跡・警告（30fps）を別スレッドに分け、検出を待たずに表示と警告を 30fps に保つ設計。Pi 4 で 1 フレームの処理は 7〜14ms
* 暗闇でも動き、顔も映らない、距離画像だけでのセンシング
* メモリ 1GB の Pi 4 で動くように、録画は 1 フレームずつファイルに追記し、読むときもメモリに全部載せない
* 腕を一瞬振っただけで鳴らないように、接近の条件が 0.2 秒続いたら鳴らす。鳴り始めは小さく、約 1 秒かけて大きくする
* 3D 表示は、ノイズを取り（浮いた点を消す、遠い点を切る）、点の密度に上限を付けて、近づいても重くならず見やすくした
* Pi とブラウザの通信形式は、Python と TypeScript の両方が同じ見本データでテストする（片方だけ変えるとテストが落ちる）

## 開発技術
### 活用した技術
#### API・データ
* Arducam ToF カメラ SDK（深度・振幅の取得）
* WebSocket（Pi → ブラウザへ、深度と人の情報を 30fps で配信。独自のバイナリ形式で 1 フレーム約 43KB）

#### フレームワーク・ライブラリ・モジュール
* YOLOX-Nano（人の検出。公式の学習済みの重み、Apache 2.0）
* ONNX Runtime（Pi での推論）
* NumPy（距離・追跡・接近の計算）
* aiohttp（Pi の Web サーバーと WebSocket）
* React＋TypeScript＋Vite（ビューア）
* three.js（3D 点群表示）
* uv（Python）、pnpm（Web）、pytest・Vitest（テスト）

#### デバイス
* Arducam ToF B0410（240×180、最大 4m）
* Raspberry Pi 4（メモリ 1GB）
* ブラウザが動く PC・スマホ

### 独自技術
#### ハッカソンで開発した独自機能・技術
* **距離画像での人の検出の高速化**：YOLOX-Nano を、センサーと同じ 4:3 の 256×192 で ONNX に書き出し直し、公式の 416×416 より約 3 倍速く、同じ精度で検出（実データで 220/220 フレーム）。振幅画像は明るさの差が大きいので、平方根で明るさをそろえてから検出する
  * [scripts/export_yolox_onnx.py](scripts/export_yolox_onnx.py)、[pi/detect.py](pi/detect.py)
* **接近の判定**：人の距離を毎フレーム測り、直近 0.5 秒の距離から接近速度と TTC を出す。「0.1 m/s 以上で近づいていて、3.5m 以内か TTC 3 秒以下」が 0.2 秒続いたら警告（実機では、人を検出できるのが 2〜3m からなので、2〜3m 手前で知らせる）。追跡は、同時に映るのはほぼ 1 人という前提で簡単にし、カルマンフィルタは見えなくなった人をつなぐ補助だけに使う
  * [pi/track.py](pi/track.py)
* **センサーの生データの癖への対応**：実データを見て分かった、深度の単位（mm）、振幅の弱い画素のでたらめな深度、上下逆さまの向きを直す
  * [pi/sensor.py](pi/sensor.py)
* **3D の点群と、人を囲む円柱**：ブラウザで深度のノイズを取り、点の密度に上限を付けて描く。人の点をそのまま囲む円柱を出す
  * [web/src/cloud.ts](web/src/cloud.ts)、[web/src/components/PointCloudView.tsx](web/src/components/PointCloudView.tsx)
* **距離で強さが変わる警告音**：3.5m で弱く、近づくほど速く・高く・鋭く・大きく。1m 未満は鳴り続け、音の質が変わる
  * [web/src/alarm.ts](web/src/alarm.ts)
* **Pi なしでも全体を動かせる偽データ**：いろいろな速さで近づく人の流れを、ノイズや抜けも入れて作り、追跡と警告のテストに使う
  * [pi/fake_sensor.py](pi/fake_sensor.py)、[web/src/demo.ts](web/src/demo.ts)
