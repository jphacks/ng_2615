# USHIROMI 実機の手順書

前提：Pi はセンサーを認識していて、uv も入っている。`<…>` の所だけ書き換える。

## 1. PC：最新にして、画面と検出モデルを Pi に送る

```bash
git switch develop && git pull
scripts/deploy_pi.sh <Piのユーザー>@<PiのIP>
```

画面のビルドと、検出モデル（なければ作る）を Pi の `~/ng_2615` に送る。画面や検出を変えたら、もう一度実行する。

## 2. Pi：最新にする

```bash
cd ~/ng_2615 && git switch develop && git pull
cd pi && uv sync
```

初めてのときは先に `git clone https://github.com/jphacks/ng_2615.git ~/ng_2615`。

## 3. Pi：センサーだけ確かめる

```bash
cd ~/ng_2615/pi
uv run sensor.py
```

1 秒ごとに `24.9 fps  測れた画素 35%  距離 0.42〜3.91 m  中央 1.23 m …` のように出れば OK。手をかざして「中央」が変わるか見る。Ctrl+C で終了。

## 4. Pi：本番

```bash
cd ~/ng_2615/pi
uv run main.py
```

表示された `http://<PiのIP>:8000/` を PC・スマホのブラウザで開き、右上の「警告音 オフ」を押してオンにする。

ログ（1 秒ごと）：`fps 25.0  処理 6.1ms  検出 5.0fps  人 1  接近 [1]  ブラウザ 1`
- fps：25 前後 ／ 処理：20ms 以内 ／ 検出：5fps 以上

検出の全力の速さを見るとき：

```bash
uv run main.py --detect-fps 0
```

## 5. Pi：録画する・流す（デモの予備）

```bash
cd ~/ng_2615/pi
uv run record.py --seconds 30 --note "後ろから近づいて止まる"
uv run main.py --recording recordings/<日時>.npz
```

録画は Git に入れない（振幅には顔が写る）。

## 6. 電源を入れたら自動で起動する（任意）

```bash
cd ~/ng_2615/pi
# ユーザー名が pi でなければ、ushiromi.service の User と /home/pi を書き換えてから
sudo cp ushiromi.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now ushiromi
journalctl -u ushiromi -f
```

止める：`sudo systemctl stop ushiromi` ／ やめる：`sudo systemctl disable ushiromi`

## 困ったとき

| 症状 | 直し方 |
|---|---|
| 画面の人が上下逆さま | `pi/sensor.py` の `ROTATE_180` を `False` に |
| 後ろに立っているだけで鳴る | `pi/track.py` の `MIN_SPEED` を 0.1 → 0.2〜0.3 に |
| 「web/dist がありません」「モデルがありません」 | PC で `scripts/deploy_pi.sh` |
| PC から開けない | 同じ Wi-Fi か、`hostname -I` の IP か |
| `センサーから 5 回続けてフレームが来ない` | ケーブルの接触。電源を切ってつなぎ直す |
